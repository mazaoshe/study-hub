# 002：共享课时余额与不可变流水

状态：已采用。日期：2026-09-30。

一个学员可持有多个课时包；一个包绑定多门课程，余额属于包。仅支持整数课时。赠送优先扣减且不得负数，付费课时可负数。

每次操作用一条 INSERT … SELECT 基于数据库当前余额计算变动；AFTER INSERT 触发器同步更新课时包。两者在同一事务中成功或回滚，避免客户端或服务端先读余额再覆盖导致并发丢账。

数据库触发器校验操作者和机构状态、变动方向、赠送余额及安全整数范围。所有业务查询限定当前身份机构，复合外键进一步约束学员、课程、课时包、操作者属于同一机构。

流水只追加，不修改、删除。冲正按原变动取反，每条原记录最多冲正一次；已归档对象仍能修正错误。若冲正充值会令赠送余额为负，拒绝该操作。

机构内唯一 request_id 配合规范化请求的 SHA-256 摘要，确保重试返回同一条记录且拒绝编号复用于其他内容。小程序把未完成的操作编号保存在本地，即便响应丢失或页面重开，重试也沿用原编号。成功后清除，下一次业务重新生成。

归档保留余额、绑定与流水，禁止新的相关业务。CSV 包含归档数据和课时包课程关系，文本字段防公式注入。

验证：集成测试覆盖共享余额、透支、并发赠送分配、重复提交、单次冲正、冲正失败回滚、机构隔离、归档与恢复、非法绑定批处理回滚以及手机丢失响应后的恢复。
